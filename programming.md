# 🏢 The Programming Station

JavaBlocks is developed at the Programming Station, where we program
code scripts to see what went wrong and what went right. The station is
focused on web apps and desktop programs, so we can update our usage.

Two rules we actually follow:

- AI for examples. HI for production code.
- AI is great for sketching, but every line that ships is written and reviewed by a human. An overconfident AI once jumped ahead and referenced a class that didn't exist yet — that's exactly the mistake the rule exists to prevent.
- If it's not "just Java", it's not a block. The moment blocks need a custom DSL or a second runtime, the whole idea falls apart.
